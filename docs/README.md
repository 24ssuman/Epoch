# Documentation

- SCIENCE.md: calculation models, approximations and primary sources.
- VALIDATION.md: scientific/API and browser verification, acceptance limits and remaining work.
- modern-validation.json: measured residuals against saved independent JPL Horizons cases.
- Screenshots, when present, document the local UI; they are not numerical validation.

- [Stellar source comparison, 20,000 BCE–5,000 CE](STELLAR_SOURCES_20000BCE_5000CE.md): catalogue epochs, long-term motion/precession, practical uncertainties and observer-time limits.

- [NASA_CROSSCHECK.md](NASA_CROSSCHECK.md) and nasa-crosscheck.json: comparison of the simulator with JPL Horizons and NASA's Five Millennium eclipse data (generated by scripts/crosscheck_nasa.py analyze from saved responses in data/references/crosscheck/).

- [PERFORMANCE.md](PERFORMANCE.md) and playback-performance.json: exact-frame benchmarks, scientific equivalence, ground-only UI and collapsible Moon phase verification.

- [MOON_LIGHTING.md](MOON_LIGHTING.md): primary lunar-light references, phase-dependent glow and its display limits.
